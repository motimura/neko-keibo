# 商品カタログ拡張 設計書

## 目的

商品サジェスト機能の静的カタログを、現在の主要41ブランド64件から約120件へ拡張する。ユーザーが個別の商品を指定しなくても、代表的な商品名、容量、枚数、個数をこちらで選定し、支出登録時の入力補助の実用性を上げる。

## スコープ

- 既存ブランドを中心に代表商品を追加する
- フードは成猫用、室内猫用、避妊去勢後、尿路/腎臓/体重管理、定番フレーバー、主要サイズ違いを優先する
- 消耗品は猫砂、システムトイレ用シート、ペットシーツ、交換フィルター、ウェットシート、爪とぎ替えを優先する
- `utils/productCatalog.ts` の静的配列のみで管理し、SQLiteやUIは変更しない
- カタログ件数変更に合わせて `CLAUDE.md` と `README.md` の表記を更新する

## データ形式

既存の `item(category, brand, productName, size, amount)` 形式を維持する。`displayName` は `brand productName size` から生成し、検索キーは既存の `normalizeQuery()` で生成する。

容量・枚数・個数は、ユーザーがそのまま家計簿の品名として理解しやすい表記にする。例: `2kg`, `400g`, `12枚`, `3個`, `4L`。

金額は市場相場ベースの目安値として扱う。実購入価格ではなく、サジェスト後にユーザーが編集できる前提の参考値とする。

## テスト方針

既存の構造整合性テストに加えて、カタログ件数が120件以上であることを確認する。既存のブランドカバレッジテストは維持し、追加商品の重複ID、必須フィールド、正規化検索キー、正の整数金額を既存テストで検証する。

## 対象外

- ファジー検索、別名検索、略称検索の追加
- SQLiteへの商品カタログ保存
- サジェストUIの表示仕様変更
- 商品ごとの価格取得や自動更新
