# 商品カタログ汎用候補 設計書

## 目的

ロイヤルカナンのように商品ラインと容量が多いブランドで、静的カタログを細かく増やしすぎずに入力しやすくする。サジェストには「ロイヤルカナン 2kg（詳細を追記）」のような汎用候補を出し、タップ後はユーザーが品名欄で詳細を追記できる入力値を入れる。詳細商品を網羅するより、容量別テンプレートを主役にする。

## 仕様

- `CatalogItem` に任意項目 `suggestionLabel` と `inputName` を追加する
- `suggestionLabel` がある場合、サジェスト一覧では `displayName` ではなく `suggestionLabel` を表示する
- `inputName` がある場合、候補選択時は `displayName` ではなく `inputName` を品名欄へ入れる
- 通常商品は既存挙動のまま `displayName` を表示・入力する
- 汎用候補は `templateItem()` で作成し、詳細商品は定番だけ残す

## 対象外

- カーソル位置の自動制御
- 専用の詳細入力画面
- 検索アルゴリズム変更
